# Crypto Support Hub

Build a clean, modern, responsive one-page cryptocurrency wallet support/help center landing page inspired by the general visual style of Trust Wallet.



Requirements:



- Make it a single-page support website only.

- Remove all login, sign-up, password, seed phrase, private key, wallet import, or account-verification functionality.

- Do not request or collect any sensitive wallet information.

- Create a prominent Support / Help Center hero section.

- Add a wallet-themed image/illustration in the hero section and a separate support/customer-help image or illustration.

- Use a professional crypto-wallet aesthetic: clean layout, rounded cards, modern typography, subtle gradients, and plenty of whitespace.

- Include a clear search bar such as “How can we help?”

- Add support categories in cards, for example:

  - Wallet & Account Help

  - Transactions

  - Sending & Receiving Crypto

  - Security

  - Network Fees

  - Troubleshooting

  - Token & Asset Issues

  - General Questions

- Add a section with popular help topics.

- Add a simple Contact Support section with a safe support form that only asks for basic information such as name, email, and description of the issue. Do not ask for seed phrases, private keys, passwords, recovery phrases, or funds.

- Add a security warning clearly stating that legitimate support will never ask users to provide their recovery phrase or private keys.

- Include a footer with Help Center, Support, Privacy, and Terms links.

- Make the entire page mobile-friendly and accessible.

- Use high-quality wallet and customer-support imagery. If external images are used, use properly licensed assets or placeholders rather than implying they are official Trust Wallet assets.

- Do not include fake testimonials, fake support-agent identities, fake verification badges, or claims that the page is the official Trust Wallet support page.

- Do not include cryptocurrency payment requests or instructions to send funds to support.



Visual direction:



- Premium Web3 support center

- White/light background with blue and green accent colors

- Rounded UI cards

- Large modern hero illustration

- Friendly but professional support imagery

- Clear CTA buttons such as “Browse Help Center” and “Contact Support”

- Responsive desktop/tablet/mobile layouts



The final result should feel like a polished crypto wallet help center, while clearly identifying itself as an independent support/help page rather than impersonating an official Trust Wallet website.
